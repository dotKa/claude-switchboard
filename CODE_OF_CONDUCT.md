# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project — issues, pull requests, discussions, reviews — you agree to abide by it.

## The short version

- Be welcoming, respectful, and constructive. Assume good intent; disagree on ideas, not people.
- No harassment, personal attacks, trolling, or discrimination of any kind.
- Respect privacy: never ask for, post, or pressure anyone to share session keys, cookies, account credentials, or other secrets.

## Reporting

Report unacceptable behavior by opening a confidential note to the maintainers via GitHub: use the repository's **Security → Report a vulnerability** flow marked "Code of Conduct", or contact the repository owner (@dotKa) directly. Reports are handled privately and in good faith.

Enforcement follows the guidelines in the Contributor Covenant 2.1 (correction → warning → temporary ban → permanent ban), at the maintainers' discretion.
